# Mockups

This folder contains static preview files for the `lilbro_researcher` frontend.

## Files

- `frontend_preview.html` — a simple visual mockup of what the web app frontend could look like

## How to view

Open the file directly in a browser, or serve it locally.

Example:

```bash
cd mockups
python3 -m http.server 8080
```

Then open:

```text
http://127.0.0.1:8080/frontend_preview.html
```
